# Change Log

All notable changes to the "pirulug-keymap" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.1.0] - 2026-04-05

### Added
- Terminal Toggle shortcut (`Ctrl+Alt+T`).
- Editor Group/Pane navigation shortcuts (`Ctrl+Alt+Left/Right`).
- Tab movement shortcuts within groups (`Ctrl+Alt+PageUp/Down`).
- Refactoring shortcuts: **Rename Symbol** (`Ctrl+Alt+R`) and **Quick Fix** (`Ctrl+Alt+Enter`).

### Changed
- Completely revamped README.md with professional design and clear documentation.
- Standardized all keybinding syntax to use `+` separator for better consistency.
- Removed all emojis from documentation to maintain a professional tone.
- Updated footer to "Developed by [Pirulug]".

### Fixed
- Redundant `when` clause in search editor matches.

## [0.0.1] - 2026-04-05

- Initial release
